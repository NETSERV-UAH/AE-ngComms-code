# Data

`Caples_Lake_N7_2014_2017.csv` is the two-column air-temperature trace used
in the experiments: 115,235 observations from June 2014 to October 2017.
The code creates a chronological split of 79,710 training, 9,220 validation,
and 26,305 test observations in the ignored `data/derived/` directory.

The file is a subset derived from:

> Bales, R.; Cui, G.; Rice, R.; Meng, X.; Zhang, Z.; Hartsough, P.;
> Glaser, S.; Conklin, M. (2020). *Snow depth, air temperature, humidity,
> soil moisture and temperature, and solar radiation data from the
> basin-scale wireless-sensor network in American River Hydrologic
> Observatory (ARHO)* [Dataset]. Dryad.
> https://doi.org/10.6071/M39Q2V

Dryad datasets are released under the
[CC0 1.0 Universal Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/).
Please cite the source dataset when reusing this subset. The repository's
Apache-2.0 software license does not replace the data terms.
